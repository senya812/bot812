# Оформление и настройка под нового клиента

Бот не привязан к названию «Outfit»: имя, слоган, текст «О бренде», баннер и аватарка меняются без правки кода.
Один бот — один магазин; для нового клиента копируете папку, меняете `.env`, картинки и токен.

## 1. Настройки бренда (`.env`)
```
BRAND_NAME=Atelier 9
BRAND_TAGLINE=Одежда с характером
BRAND_ABOUT=Шьём в Москве с 2019 года.\nТолько натуральные ткани.
CONTACT_URL=@atelier9_manager
```
- `BRAND_NAME` и `BRAND_TAGLINE` попадают в приветствие, на страницу «О бренде» и в описание бота в профиле
  (бот сам обновляет его при запуске).
- `CONTACT_URL` необязателен: если пусто, кнопки «Написать нам» нет.

## 2. Картинки
```bash
pip install pillow
python tools/make_banner.py --brand "Atelier 9" --accent "#D6BC8A" --bg "#151413"
# по желанию — строка под названием на баннере: --tagline "Одежда с характером"
```
Появятся три файла в `assets/`:

| Файл | Куда |
|---|---|
| `banner.png` | приветствие в боте (подхватывается автоматически) |
| `avatar.png` | @BotFather → `/setuserpic` (на ней название целиком, для длинных названий — первая буква) |
| `description.png` | @BotFather → `/setdescriptionpic` (картинка над кнопкой «Старт») |

Палитры, которые хорошо смотрятся:

| Настроение | `--bg` | `--accent` |
|---|---|---|
| Классика (по умолчанию) | `#151413` | `#D6BC8A` |
| Минимализм | `#1B1B1F` | `#E8E2D6` |
| Шалфей | `#10161A` | `#9FB8A5` |
| Пудровый | `#1A1415` | `#D9A5A0` |

Баннер можно заменить своим дизайном: положите файл в `assets/banner.png` или укажите путь в `WELCOME_PHOTO`.

## 3. Что бот делает сам, а что вручную
- Сам: меню команд, описание и короткое описание в профиле, баннер в приветствии.
- Вручную в @BotFather: аватарка (`/setuserpic`) и картинка описания (`/setdescriptionpic`).
- Вручную в боте: `/admin` → категории и товары. Фото товаров снимайте на одинаковом фоне
  и в одном формате (лучше 4:5) — карточки сразу выглядят дороже.

## 4. Советы по наполнению
- Названия короткие и без КАПСА: «Тренч оверсайз», а не «ТРЕНЧ ОВЕРСАЙЗ СУПЕР КАЧЕСТВО».
- Описание в 2–3 строки: материал, посадка, уход. Без эмодзи — стиль выдержан без них.
- 5–10 вещей в категории: листать приятно, не утомительно.
