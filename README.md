# Outfit bot

Telegram-витрина одежды: каталог по категориям, карточки с листанием, «Мой образ» (подборка вещей
с суммой) и панель админов (категории, товары, **учёт размеров и остатков**, статистика, рассылка).
Заказов и оплаты нет — это витрина. Админов может быть несколько (`ADMIN_ID=111,222`), у всех равные права.

## Запуск
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN и ADMIN_ID
python main.py
```
Нужен Python 3.9+ и aiogram 3.7+. Существующий `shop.db` подхватится сам: при старте из него убираются дубли
и «осиротевшие» записи образа.

## Тесты
```bash
python -m unittest discover -s tests -t . -v     # без внешних зависимостей
```
Ручной чек-лист перед релизом — в `TESTING.md`.

## Структура
| Файл | Что внутри |
|---|---|
| `main.py` | запуск, меню команд, глобальный обработчик ошибок, фильтр «только админ» |
| `user_handlers.py` | клиентская часть: каталог, карточки, образ |
| `admin_handlers.py` | админка, добавление/удаление, рассылка |
| `stock_handlers.py` | остатки по размерам: быстрая продажа сообщением, кнопки, журнал, отмена (`STOCK.md`) |
| `ui.py` | все клавиатуры |
| `messaging.py` | общие помощники отправки/редактирования |
| `database.py` | SQLite |
| `utils.py`, `config.py` | форматирование, разбор callback-данных, настройки и бренд |
| `tools/make_banner.py` | рисует баннер, аватарку и картинку-описание (`BRANDING.md`) |
| `assets/` | готовые баннер, аватарка и картинка-описание |

## Два вида каталога
В `.env` параметр `CATALOG_MODE`:
- `carousel` (по умолчанию) — одна карточка, листание кнопками ‹ ›. Чат не засоряется.
- `feed` — лента: вещи категории идут сообщениями подряд (по 10, дальше «Показать ещё»), под каждой кнопка «♡ В образ».
  Кнопка «↩️ Назад» удаляет все эти сообщения из чата. Лента также убирается сама, когда клиент открывает другую категорию,
  «Мой образ» или любой раздел меню. Telegram не даёт боту удалять сообщения старше 48 часов — такие останутся в чате.

## Админка
`/admin` (для всех из `ADMIN_ID`). Отмена любого диалога — `/cancel`. Учёт размеров — `STOCK.md`.
В рассылке текст можно форматировать обычными средствами Telegram (жирный, курсив, ссылки);
перед отправкой бот показывает предпросмотр.

## Необязательные настройки `.env`
`PROXY_URL` — прокси для Telegram, `WELCOME_PHOTO` — свой баннер (путь, file_id или ссылка), `DB_PATH` — путь к базе, `TZ_OFFSET` — часовой пояс для журнала остатков (по умолчанию 3).
Название, слоган и текст «О бренде» — в `.env`, см. `BRANDING.md`.
