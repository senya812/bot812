# Ручной чек-лист (на тестовом боте)

Создайте второго бота в @BotFather для тестов и отдельный `.env`. Нужны два аккаунта: админ и клиент.

## Клиент
- [ ] `/start`: баннер с приветствием, меню внизу («Каталог», «Мой образ», «О бренде»), список категорий. Имя с символами `<` `&` не ломает сообщение
- [ ] «О бренде» / `/about`: название, слоган, текст; кнопка «Написать нам» есть только если задан `CONTACT_URL`
- [ ] Пустой магазин: «Каталог пока пуст», без ошибок
- [ ] Категория без товаров: «пока ничего нет» + кнопка в каталог
- [ ] Листание ‹ › меняет карточку на месте (без мерцания), по кругу: с последнего на первый
- [ ] Счётчик «2 / 5» верный; при одном товаре стрелок нет
- [ ] «♡ В образ» → тост без всплывающего окна, кнопка меняется на «♥ В образе», счётчик «Мой образ · N» растёт
- [ ] Повторное нажатие убирает вещь; дубли в образе невозможны
- [ ] 21-я вещь: сообщение о максимуме (20)
- [ ] Мой образ: список, сумма пересчитывается при удалении вещи ❌ и «Очистить»
- [ ] Кнопки меню внизу и команды `/catalog` `/look` `/about` `/help` работают
- [ ] Произвольный текст → подсказка про меню
- [ ] Название товара с `_ * [ < &` отображается как есть
- [ ] Старые кнопки из прошлой версии бота не работают — это нормально, достаточно `/start`

## Устойчивость
- [ ] Админ удалил товар, пока клиент смотрит его карточку: нажатие ▶️ или «Добавить» не падает
- [ ] Админ удалил категорию, пока клиент в ней: возврат в каталог
- [ ] Клиент нажимает кнопку на очень старом сообщении: нет ошибок в логе
- [ ] Бот перезапущен: образ и каталог сохранились
- [ ] Если баннер не отправляется (битый файл) — приветствие приходит текстом, без ошибок

## Админ
- [ ] `/admin` у клиента ничего не делает; у админа открывает панель
- [ ] Добавить категорию: пустое имя, имя 41+ символов, команда вместо имени — отклоняются
- [ ] Добавить товар: цена `abc`, `0`, `-5`, `12.5` — отклоняется; `4 990` — принимается; вместо фото текст или файл — подсказка
- [ ] `/cancel` посреди добавления товара сбрасывает диалог
- [ ] Удалить товар: после удаления список обновляется, можно удалять дальше
- [ ] Удалить категорию: сначала подтверждение с числом товаров
- [ ] Статистика: числа совпадают с реальностью (после удаления товара «клиентов с образом» уменьшается)
- [ ] Рассылка: текст с жирным → предпросмотр → «Отправить»; с картинкой и без; «Отмена»; повторное нажатие «Отправить» ничего не запускает
- [ ] Рассылка при заблокированном боте клиенте: в итоге учтён в «Заблокировали»
- [ ] Повторный `/start` админом посреди диалога сбрасывает его

## Режим ленты (`CATALOG_MODE=feed`)
- [ ] Категория: вместо списка категорий появляется заголовок «Куртки · 7 вещей», ниже вещи отдельными сообщениями, в конце «Это всё в этой категории»
- [ ] Под каждой вещью «♡ В образ» работает и меняется на «♥ В образе»; размеры и «арт.» видны
- [ ] «↩️ Назад»: все вещи исчезают из чата, снова виден список категорий
- [ ] Категория больше 10 вещей: «Показать ещё (N)» добавляет следующую порцию; «Назад» убирает все
- [ ] Открыть другую категорию, не нажимая «Назад»: прошлая лента удаляется сама
- [ ] «Мой образ» из ленты и кнопки меню внизу тоже убирают ленту
- [ ] Перезапуск бота при открытой ленте: «Назад» всё равно возвращает каталог (часть сообщений может остаться)
- [ ] Категория на 30+ вещей: сообщения приходят без ошибок (при желании переключитесь на `carousel`)

## Размеры и остатки (два админских аккаунта)
- [ ] `ADMIN_ID=111,222`: оба видят `/admin`, оба могут открыть «📦 Остатки»; клиент — нет
- [ ] Новый товар: после фото просит размеры; `S2 М3` (с русской «М») принимается; `S`, `S2 S3`, `abc` — понятная ошибка
- [ ] После добавления бот называет номер товара (№…)
- [ ] У клиента в карточке строка размеров и «арт. №»; закончившийся размер зачёркнут; при 1–2 шт. — «Осталось мало»
- [ ] Все размеры по нулям → «Нет в наличии»; товар без размеров — строки нет
- [ ] Сообщение `12 M` списывает 1 шт., `12 M 2` — 2 шт., `12 M +3` добавляет; в ответе есть «Отменить»
- [ ] Ошибки: неверный номер, нет размера, нет заведённых размеров, списать больше остатка — остаток не меняется
- [ ] Продажа до нуля: второй админ получил «размер закончился», сам продавший — нет
- [ ] Кнопочный режим: продажа и приход, «Отменить последнее» на экране и на главной странице раздела
- [ ] Отмена дважды подряд — второй раз «уже отменена»; отмена, после которой остаток ушёл бы в минус, — отказ
- [ ] «Задать размеры»: заменяет список целиком; `-` выключает учёт; `/cancel` выходит
- [ ] «Журнал»: имена админов (не числа), время в вашем часовом поясе (`TZ_OFFSET`)
- [ ] Удалён товар, в журнале он помечен «удалён»; ошибок нет
- [ ] Клиент пишет боту `12 M` — получает обычную подсказку и ничего не списывается

## Перед публикацией
- [ ] Токен не в репозитории (`.env` в `.gitignore`); если светился — перевыпущен в @BotFather
- [ ] В @BotFather загружены аватарка (`assets/avatar.png`) и картинка описания (`assets/description.png`); меню команд и описание бот ставит сам
